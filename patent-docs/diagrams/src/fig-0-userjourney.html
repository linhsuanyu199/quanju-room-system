短租排房系統　使用者路徑流程圖

自帳號開通至營運回饋之完整作業流程
附圖零
使用者
操作企業內部人員
與外部房客
1開通與加入
註冊帳號以電子郵件與密碼建立個人帳號
分支：建立新企業成為管理員並取得專屬邀請碼
分支：加入既有企業輸入邀請碼即與同事共用資料
設定顯示名稱作為訂單負責業務之識別
2建置房源
新增館別填寫縣市、行政區與地址
逐間設定房間房號、房型與月租金
或以試算表批次匯入大量房源一次建檔
選用：開啟估價問卷試算合理租金後回填
3對外曝光
勾選公開房間逐間決定是否對外顯示
複製官網連結分享至社群或通訊軟體
房客瀏覽公開官網免登入查看可租房源
房客送出預約詢問留下聯絡方式與需求時段
4成立訂單
接收詢問並聯繫於收件匣標記處理狀態
選擇房間與住退日期送出前即時檢查是否衝突
需換房則新增分段同一訂單可含多段不同房間
填寫房客與收款資訊來源、負責業務、付款方式
5住中與退房
推進訂單狀態預定中 → 已付款待入住 →
入住中 → 已退房
處理清潔任務指派負責人並回報完成
登錄維修事項填寫金額與屋主請款狀態
續約或換房於原訂單延長或新增分段
6經營與決策
檢視營運報表入住率、營收與維修成本
經營既有客戶客戶列表與生日、節日祝福
查詢同區行情參考彙總統計調整訂價
匯出資料備份房源與訂單清單試算表

自動處理使用者無須
額外操作
企業識別由伺服器蓋章 建立或加入企業後，該使用者之企業識別由後端核發；此後所有讀寫皆自動綁定該識別，前端無從指定他企業。
估價結果跨站回填 估價站以指定來源網域回傳結果，主系統驗證來源後存檔；套用為月租時保留原價，可隨時還原。
詢問單即時進線提示 訪客免登入送出之詢問，經後端安全函式寫入指定企業；主系統選單即時顯示未讀數量紅點。
衝突偵測與覆蓋防護機制一・五 同房重疊區間即時攔截並指出衝突訂單；儲存前重新取回最新資料，避免覆蓋他人同時新增之訂單。
退房後自動排程機制三 訂單轉為已退房即自動產生清潔待辦並鎖定該房間，任務回報完成後才恢復為可售，同步留存異動歷程。
去識別化行情回饋 成交資料去除門牌與房客資訊後彙入跨企業行情池；查詢僅回傳樣本數達門檻之彙總統計，不揭露單筆來源。

流程說明：上排為使用者實際操作之步驟，下排為系統於同一階段自動完成之處理，兩排上下對應。 使用者僅需依序填寫業務資料，衝突攔截、退房後排程、跨站資料回填、企業資料隔離與行情去識別化均由系統自動執行，無須額外操作。
